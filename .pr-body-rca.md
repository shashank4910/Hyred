## Summary
Structural RCA fixes (not site-specific):
- **Resume picker:** Apply/Optimize handoff now wins over fuzzy IRC/title hint matching; hint queries prefer matches that already have tailored resume.
- **Autofill crash:** Choice/dropdown widgets (`role=combobox`, custom selects) no longer go through `HTMLInputElement.value` setter (`Illegal invocation`).
- **Partial fill:** Per-field error isolation — one bad widget cannot abort the entire run.
- **Engine taxonomy:** `notice_period`, `years_experience`, `gender` classified as `choice` → dropdown path, not text.
