## Summary
- Workday was getting **5 duplicate cover-letter attachments** because `attachFileToInput` fired input/change on two file inputs plus a drop event — Workday treats each as a new upload.
- Now fires **one** input+change on a single target (same pattern as resume upload).
- Skips upload when the form already shows a cover letter attached.
- Adds a **per-tab upload lock** so fan-out autofill across Workday iframes cannot each attach the same PDF.
