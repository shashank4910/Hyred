# Fix Studio UX redesign (Aug 1, 2026)

## Goal
Make Resume Fix Studio feel like the Stitch mockup: clear hierarchy, one primary action, Before/After fixes, circular score, step progress.

## Constraints
- Keep Suggest / Apply / Undo / quota / freemium report logic
- Hyred Luminous tokens (`primary` teal, Plus Jakarta Sans)
- Shared rail for logged-in + public

## Layout
1. Header: title + Beta · circular score · Undo / Save / Copy
2. Steps: Scan → Review → Apply → Download
3. Body: Score rail | Fix card (Before/After)
4. Bottom: Original | Hyred twin

## Out of scope
- New scoring engine criteria
- Stripe checkout
