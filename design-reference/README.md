# Design Reference

Upload your UI redesign reference image(s) into this folder.

## How to upload via GitHub web UI

1. Open this folder on GitHub:
   `https://github.com/shashank4910/JobRadar/tree/design/ui-redesign-reference/design-reference`
2. Click **Add file** -> **Upload files**.
3. Drag-and-drop your reference image(s) here (PNG or JPG preferred).
4. Commit directly to the `design/ui-redesign-reference` branch.

## Naming

Name the main reference something clear, e.g.:

- `reference.png` (primary full-page design)
- `card.png` (close-up of cards, optional)
- `colors.png` (palette/typography reference, optional)

Once uploaded, let Kiro know and the redesign will begin using these as the
single source of truth for colors, typography, cards, and layout.
